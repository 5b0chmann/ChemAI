# ChemAI

## Current Version
**v0.7.1 Machine Learning Foundations**

## Current Objective

Build machine-learning-ready representations of atomic and electronic environments as a foundation for future spectroscopic prediction.

## Overview
ChemAI is a cheminformatics and machine learning project focused on understanding molecular structure, electronic environments, and spectroscopy.
